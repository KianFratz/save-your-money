# Separate allowance disbursement from allowance use

The app records the user's allowance disbursement as one account-affecting financial event, then records the sister's Needs, Wants, and Savings uses against that allowance without changing the user's account again. Treating these as separate concepts avoids double-counting the same money while still supporting both the user's real account history and detailed oversight of how the allowance is used; Savings uses are classified by ordinary Savings categories rather than a separate destination model.
